# Раскрытие использования ИИ

Ада / Codex подготовила черновик реализации классов Book, SampleId, DataSample и SampleRegistry. Проверочный набор AcademicContractsTest фиксирует сценарии из условия.

Проверено Maven/JUnit через Academic Executor. Существующие файлы других лабораторных и конфигурация Maven сохранены.

На защите самостоятельно объясни согласованность equals/hashCode, коллизию Aa/BB, замену значения и эксперимент с изменяемым ключом.
